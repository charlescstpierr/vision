# Vizion

Éditer des sites web « live » depuis Microsoft Edge ou Chrome, avec un agent de code (Codex CLI ou Claude Code) qui applique les modifications.

- Sélectionne un élément dans la page, décris le changement, l'agent modifie le code source.
- Sur un site sans code source local, les modifications sont appliquées au DOM et persistées dans le navigateur.

Voir [docs/PLAN.md](docs/PLAN.md) pour l'architecture et le plan de réalisation.
